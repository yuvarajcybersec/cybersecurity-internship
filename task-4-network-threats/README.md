# Objective

The objective of this task was to research and analyze common network security threats, understand how these attacks operate, examine their real-world impact, and identify practical mitigation strategies that organizations can implement to improve network security.

---

# Introduction

Modern organizations rely heavily on computer networks for communication, cloud services, financial transactions, and business operations. As network connectivity increases, the attack surface also expands, making networks a primary target for cybercriminals. Attackers may attempt to disrupt services, intercept communications, impersonate trusted systems, or redirect users to malicious destinations. Understanding these threats is essential for network administrators, security analysts, and cybersecurity professionals because effective defense begins with a clear understanding of how attacks occur and how they can be prevented.

---

# Topics Covered

The research report investigates the following major network security threats:

* Denial-of-Service (DoS) attacks
* Distributed Denial-of-Service (DDoS) attacks
* Man-in-the-Middle (MITM) attacks
* IP Spoofing
* DNS Poisoning / DNS Spoofing

For each threat, the report explains the attack mechanism, discusses a real-world example, analyzes the impact, and recommends mitigation strategies.

## IP Spoofing

* Packet source address forgery

## DNS Poisoning

* Redirection to malicious websites
