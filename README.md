This repository contains the cybersecurity internship tasks completed as part of the internship program. The submission includes both practical and research-based cybersecurity exercises covering network reconnaissance, network security threats, social engineering attacks, and patch management.

The objective of this repository is to demonstrate foundational cybersecurity skills, ethical security practices, technical analysis, and professional documentation using GitHub and Markdown.
